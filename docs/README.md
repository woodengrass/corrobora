## 閱讀時要分清楚

- 本計畫提出的流程、API、資料欄位與目錄，除非現況文件列出可運行程式及結果，都是待實作。
- 既有文獻做過的功能，不因換名稱或改用 Minecraft 就變成新貢獻。
- 對照結果若顯示原始紀錄或普通筆記已足夠，應簡化方法。沒有顯著優勢不等於證明等效，也不自動保證負結果足以發表。
- 全部範例產量、假設、故障與成本均須由實驗確認；不得當作某遊戲版本的已驗證機制。
