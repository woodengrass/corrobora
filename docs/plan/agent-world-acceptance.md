# 模型接入與世界介面驗收

[索引](../README.md) · [介面規格](agent-world-interface.md) · [實作順序](06-roadmap.md) · 2026-10-08

以下全部是待執行測試，不是通過紀錄。介面正確、模型會操作工具、農場研究假說成立，是三個不同驗收層次。只以可定位的實際結果判定，不以主觀完成百分比代替。

## 1. 不接模型的契約與整合測試

| ID | 測試／預期 | 阻擋範圍 |
| --- | --- | --- |

| W05 | read 不推進遊戲、不生成／載入新 chunk；大區域先限額再掃描 | 所有研究 |

## 2. 模型工具使用檢查

正式農場前使用獨立、簡單的教學場景，要求模型：讀取指定方塊狀態、從切片定位容器、取得第二頁資料、提出合法 patch、看到 stale error 後重新讀取、運行固定 ticks、提交測試與設計。

這不是新方法成績。模型無法使用 schema、座標或工具時先修共同介面，不只替 CDET 加人工提示。教學次數、示例與版本在各組固定，重試及人工協助記錄，不包含正式農場故障與理想修復。

## 3. CDET 控制程式測試

| ID | 固定規則需要做到 |
| --- | --- |
| G01 | 零個必要前提不自動視為通過，回到一般調查或重新提出方案 |
| G02 | 白名單 validator 有當前且完整的證據才回 supported；引用存在不等於語意已驗證 |
| G03 | contradicted 阻止原樣重用；unknown 只允許上限內補查，超限後退回 |
| G04 | tool error、partial、expired evidence 不被轉成前提已通過 |
| G05 | 同一凍結提案、證據與配置得到相同控制決策；不在判定內暗呼叫 LLM |
| G06 | 父世界改動／推進後動態通過紀錄失效；診斷副本結果不可無條件嫁接 |
| G07 | 停用研究 gate 不會停用安全、區域與預算限制 |
| G08 | 拒絕後改提新程序有新 ID 與成本；一般調查路徑可用並另記，不聲稱完全封鎖模型心中重用 |

通過只代表程式遵守規格。前提是否合理、是否誤擋有效程序、是否改善修復，必須另以遊戲實驗比較。

## 4. 最小端到端驗收

由同一 manifest 啟動乾淨世界，人工核對初始輸出；模型取得 bootstrap、探索結構、提出有引用的區域解釋、鎖定一個測試、在副本執行、回到父世界修改、提交獨立驗收。正常成功與至少一種合法失敗都必須留下可重播紀錄。

完成判準是可追查每一個決定拿到哪些觀察、花了多少成本、世界是否改變，以及分數由何處計算，不是要求模型這次一定成功。使用 [P1 記錄表](../experiments/p1-interface-smoke.md)。

## 5. 阻擋與放行

座標、計分、資料隔離、時間或重置不可靠時，不開始方法效果比較。缺少 render 或進階 sensor 不必擋住結構化首版，但不能宣稱擁有未實作能力。

先放行一座農場、不接模型的自動量測；再放行一個模型與少量開發題；最後才進入提示／證據／規則比較。每一級更新 09 的證據位置，不把文件覆蓋率當程式完成度。
