# 00｜研究總覽

[文件索引](../README.md) · 更新：2026-10-02 · 狀態：待實作計畫

## 1. 白話說，我們要研究什麼？

讓 AI 設計、運行、診斷與改良 Minecraft 的完整生電農場，研究它做過前面的工程任務後，能否更有效地處理新的設計；也研究舊經驗何時會把它帶往錯誤方向。

第一個可檢驗問題是：**在相同模型、工具、可用證據與預算下，重用過去的診斷實驗之前先確認適用條件，是否能改善新農場的成功率與實驗成本，並減少錯誤重用？**

Minecraft 是實驗平台，不是研究結論的適用範圍保證。即使結果成立，也只能先主張在所測農場、條件與模型上的效果，不能直接推廣到真實工廠。

## 2. 一個具體但尚未實測的例子

農場 A 的輸出偏低。Agent 比較生產、運輸與收集階段的觀察，在隔離副本中測量下游容量，最後找到限制並修改設計。下一座農場 B 也低產，卻可能是生產端不足。

希望留下的經驗是「怎樣區分這幾種原因，以及什麼条件下這個測試有效」，而不是「低產量就增加收集設備」。新任務要能重用有效程序，也能拒絕相似但不適用的舊解法。

這是研究情境，不代表每座農場都有可獨立相乘的生產／運輸／收集效率，也不預設 AI 一定會犯上述錯誤。

## 3. 長期目標與第一篇的邊界

完整工程迴圈是：需求 → 設計 → 建造 → 運行 → 測量 → 診斷 → 修改 → 完整驗證 → 下一座農場。

第一階段從有起始設計的 `repair_optimize` 任務開始；環境可靠後，再加入不提供完整藍圖的 `design_build`。維修、改良與從需求設計分開報告，不能用修好的現成農場證明已會自主設計。

第一篇不要求走路採礦、不訓練基礎模型、不改遊戲規則、不做任意 harness 自我重寫。跨遊戲版本、跨模型接棒及工具庫全面治理都是後續選項，不是必做清單。

## 4. 三種成果不能混稱

| 實際改進 | 需要的證據 | 不能直接推出 |
| --- | --- | --- |
| 同一座農場變好 | 固定規則下的產出、穩定性與約束驗收 | Agent 已經持續學習 |
| 經驗讓新農場更容易解決 | 凍結歷史、未見任務、公平對照與完整成本 | 模型權重改變或具有完整世界理論 |
| Agent 改善自己的學習流程 | 流程變更後，在另一批未見問題再次受益 | 無限制的遞迴自我加速 |

本研究先爭取第二項。即使未提出有效新方法，完整實驗仍可能釐清經驗的效益與傷害；是否構成有價值的實證貢獻，要看問題新意、比較深度與證據品質。

## 5. 最小架構

```text
公開任務與限制
    |
可替換的模型 + 固定的一般 Agent 執行框架
    |                          ^
受限工具介面                 可搜尋的原始紀錄
    |                          + 按組別提供的經驗
Minecraft 建造／診斷世界 ------+
    |
凍結設計 → 獨立新世界驗收 → 封存成績
```

Agent 決定查什麼、測什麼與改什麼；工具層控制區域、材料、時間、檔案與權限。固定評分器不能被 Agent 改寫。原始觀察、推導出的經驗、這次的臨時計畫分開保存。

## 6. 候選方法的位置

工作名稱仍用 CDET，意指「有條件地轉移診斷經驗」，不是原創性或有效性的認證。最小候選流程是：取回舊實驗 → 對應新設計中的觀察位置 → 檢查前提 → 產生幾個能區分原因的測試 → 選一個成本合理且會影響決策的測試 → 修正設計或經驗 → 完整驗收。

先跑強基線，確認實際問題，再決定保留哪一步。不可禁止基線自行反思、查條件或生成測量腳本；我們要測的是額外結構或控制策略的淨收益。

[詳細方法](04-experience-method.md) 是可刪減的研究提案，不是需要無條件實作的產品規格。

## 7. 本輪文獻更新改變了什麼？

[SciCrafter](https://arxiv.org/html/2604.24697v2) 已有紅石實驗、知識整理與應用迴圈；[MCMA](https://aclanthology.org/2026.findings-acl.1535/) 已研究記憶抽象與選擇性轉移。因此不能聲稱前人只會存筆記，或只要加適用條件就是新方法。

9 月 28 日的 [JAM](https://arxiv.org/abs/2609.34385) 提出保留完整歷史、在查詢時重新研究證據的方向。這使「強 Agent＋可搜尋原始紀錄」更不能被設成弱基線。9 月下旬其他修正、記憶路由與實驗管理工作也已進入本輪比較表，閱讀程度與限制見 [08](08-related-work.md)。

沒有找到完全相同的完整農場研究，不等於證明全球第一。現阶段能合理承諾的是把問題定義清楚、提供可重跑環境與比較，不能保證方法勝出或科展名次。
