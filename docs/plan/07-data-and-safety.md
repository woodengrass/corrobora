# 07｜資料來源、原始證據與安全

[索引](../README.md) · [測試環境](03-farm-testbed.md) · 2026-10-02

本文件取代舊資料平台的來源政策。保留仍有效的限制，但不要求舊資料庫 schema 或匯入流程。以下授權狀態多為既有紀錄，不代表本輪已逐一取得新的授權確認，也不是法律意見。

## 1. 三種不同判斷

來源可追溯，不代表內容正確；內容正確，不代表可以公開散布；檔案已在公開 repository，也不表示權利與隱私問題自動解決。

hash 僅用於內容身分。引用存在、文字支持、程式執行、預測吻合、修復有效與允許發布應分開記錄，不設一個含糊的 trust_level 取代全部判断。

本輪保留 `raw-data/` 與既有評測 fixture 的來源 bytes，不以新規劃改寫它們。部分既有素材的舊政策標為 internal，與 repository 目前公開可見的狀態需要擁有者另行審查；保留檔案不是認定已獲公開或外部模型傳送許可。

## 3. 新農場資產的登錄

每座農場記自建／改編、作者、原始 URL、來源版本、取得日期、授權文字／定位、允許研究／外部模型／公開散布的範圍、修改內容和檔案 hash。

有影片或目錄紀錄不代表持有藍圖 bytes；有藍圖 bytes 也不代表已能運行。取得、解碼、來源確認、人工 reference 驗證與正式測試狀態各自記錄。

優先採自建或明確允許所需用途的設計。授權不明時可記問題但不默認公開；正式發布前逐項檢查。競賽、論文或重現性要求不會自動豁免來源限制。

## 4. 原始證據與修訂

原始實驗的設定、初始快照、操作、事前預測、原始觀察與用量由 runner 追加保存。錯誤記錄以更正事件處理，不直接改成當初就正確。

Agent 對經驗的摘要和解釋可以版本化修正，但應指回原始 evidence。一次測試吻合只支持該次條件，不升級成普遍規則。某來源更新可触發重查，不自動表示所有依賴結論為假。

研究者可以排除符合預定政策的基礎設施異常，但要保留原因與原紀錄。不能以「清理無用資料」為名刪除方法失敗、負結果或不利試驗。

## 5. 工具與程式邊界

Agent 的分析程式運行在隔離工作區，限制 CPU、記憶體、時間、輸出、網路與掛載路徑。不能讀 host 憑證、其他實驗組歷史、私有標籤或評分器程序，也不能直接寫世界檔案繞過工具。

Agent 可以產生受限測量與分析腳本；固定原始事件擷取和正式評分不可由它替換。第三方套件或 repository 的下載／執行不是默認權限，需固定依賴與審查來源。檔案 hash 和 lockfile 可定位版本，但不等於程式安全。

最低威脅模型包含：文件中的不可信指令、惡意或錯誤工具輸出、依賴替換、路徑逃逸、分數造假與跨組資料洩漏。這些是實驗可信性的工程底線，不在第一篇擴展成資安研究。

## 6. 評分與研究資料隔離

正式驗收在新的隔離世界執行。診斷注入物、成品初始庫存、非法命令與偽造計數不能提高分數。公開工具與私有 evaluator 使用不同權限。

保留測試標籤、參考最佳修复與 seeds 不放進 Agent 可讀檔名、metadata、例外訊息或 log。角色與瓶頸的人工答案也不可免費提供給處置組。公開規格仍需充分說明任務要求，不能把未告知的需求藏成公平測試。

## 7. 外部模型、日誌與公開發布

在傳送資料到模型供應商前，確認來源允許該用途。沒有把握的內部 corpus 不作第一輪 baseline 的默認輸入；可先用自建農場與可發布紀錄。

不記錄 API keys、token、私人憑證或不必要的個人資料。保存工具動作、可檢驗假說、預測與簡短決策理由，不要求存取模型私有思考過程。

公開包可包含自建／授權設計、adapter、評分規格、去識別化 raw traces、結果與重跑指引。遊戲程式由使用者依法自行取得；只發布必要的配置與校驗資訊。研究獨立性、AI／教師協助及競賽規則另記於 [09](09-status-and-deliverables.md)。
