# 01｜研究問題、假說與貢獻邊界

[索引](../README.md) · [評測](05-evaluation-protocol.md) · 更新：2026-10-08

## 1. 操作定義

研究單位是一個 Agent 在明確預算、歷史和工具下處理一座完整農場；證據是事前預測、工具行動、可驗收設計與成本，不是模型自稱理解。

經驗是過去允許取得的設計、操作與觀察及衍生摘要，不含未來答案。正向遷移指相對公平基線提高成功或在品質可接受下減少成本；負向遷移需可重現的表現劣化，單次配對失敗不足以歸因某條記憶。

事前干預預測、可辨識故障與未見組合修復只是理解的代理證據，不保證唯一因果模型。歷史增加後在固定未見題的改善可稱系統層級經驗轉移，不暗示完成權重訓練或 RSI。

## 2. 研究問題

| RQ | 問題 | 證據與反駁 |
| --- | --- | --- |
| RQ1 | 哪些歷史對新農場有益、無關或有害？ | B0/B1/B2，獨立適用性與條件差異；無穩定效應就不主張存在普遍傷害 |
| RQ2a | 額外指定檢查是否有價值？ | I1 對 I0，完整計檢查成本；效果可來自新資訊或程序安排 |
| RQ2b | 相同檢查結果下，固定執行規則是否有增量？ | I2 對 I1；主要看功能／成本／誤擋，不以遵守率自證 |
| RQ3 | 怎麼在相同候選池中選有用測試？ | 獨立比較 S1、最便宜、自由選；生成品質與排序效果分開 |
| RQ4 | 效果能否跨設計且保留舊有效經驗？ | 留出 lineage／組合／條件、回歸及模型內重跑；近重複收益不算跨家族 |

先做 RQ1 與 RQ2。若 P2 顯示主要缺口是測試選擇，可獨立先測 RQ3；不要求 gate 先有效。未實際量測的 RQ 不列為成果。

## 3. 可反駁假說

H1：同一經驗在有效前提下可省調查，在相似但條件不同情境可能增加錯誤或成本；也容許沒有穩定效應。

H2a：在相同總預算下，指定前提檢查得到的資訊可能改善新農場決策，但成本可能抵銷效益。

H2b：同樣前提結果和方案下，固定 gate 可能比模型自主決定更可靠，也可能因前提不完整／過嚴而誤擋有效方案。

H3：固定候選池的選擇方法有可重現差異；分歧分數僅為待測啟發式，不預設優於模型。

數值門檻、效應量、預算與正式分析於 dev/pilot 後、保留集開封前鎖定。不能看 test 後改假說。

## 4. 分清來源與控制的作用

B1/B2/B4 的端到端差異可能同時包括檢索、上下文、提示、工具與維護成本，不能直接當單一機制效果。E1 凍結同一歷史；I1/I2 再凍結同一方案／檢查結果，才隔離指定執行政策。

前提由模型生成仍可能錯，程式僅驗可執行條件，不代替領域理解。gate 限制的是明確重用路徑，模型可回一般調查，不能宣稱封鎖所有隱性重用。

E2 自主累積中各組產生不同證據，結論是整體政策效果，不是單純 schema 效果。因果主張需配對、獨立重跑及相應消融；讀模型理由不足。

## 5. 完整農場與合法解法

需要有一部分案例實測呈現上下游相依、局部與整體效果不同，才有充分理由使用完整農場。簡單控制仍保留，耦合標籤不是用方法勝負決定。

repair_restricted、free_optimize、design_build 分開。合法整體替換不能當作弊，但不能憑重建成功聲稱診斷遷移成立。修改軌跡與成本全記，不能事後只挑局部修復成功資料。

全部候選與排除理由保存。可行候選集與刻意篩選的困難子集分開，沒有代表性抽樣不推廣到所有生電。

## 6. 貢獻可能是什麼

評測：新的可重現任務能區分藍圖重用、程序轉移、前提檢查與局部修復，並有強基線；只增加方塊數不足。

方法：具體可檢查決策相對已有方法／簡單流程有淨收益。MCP、資料庫、卡片格式、縮寫和一般 gate 都不是自動的演算法創新。

實證：釐清經驗條件、資料表示、模型能力與檢查成本如何影響功能；負結果也需新資訊與足夠證據，不自動可發表。三種成果不必硬湊，題目依完成範圍。

## 7. 更強模型與研究界線

模型可能自行善用原始歷史，外部規則不一定必要。換模型時該模型內重跑全部主要組，不拿舊模型基線對新模型方法。介面教學、時間、感測與資料精度也一致。

[08](08-related-work.md) 的先例與查核限制持續有效。本輪是把方案變成可識別的規格，不等於確認原創性、科展資格、方法有效或已有實驗數據。
