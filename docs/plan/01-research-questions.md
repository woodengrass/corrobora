# 01｜研究問題、假說與貢獻邊界

[索引](../README.md) · [實驗協定](05-evaluation-protocol.md) · 2026-10-02

## 1. 研究對象與操作定義

研究單位是「一個 Agent，在特定預算與可用歷史下，處理一座完整農場的工程任務」。觀察的是可提交的設計、實驗選擇、結果與成本，不是模型自稱的理解程度。

- **經驗**：過去允許取得的設計、操作、觀察及其摘要或程序，不含未來任務答案。
- **正向遷移**：相較同條件基線，既有經驗提高成功率，或在品質可接受時降低成本。
- **负向遷移**：經驗導致表現較差的可重現效應。單次配對失敗只能先記為差異，不能直接歸因某條記憶。
- **理解的代理指標**：事前干預預測、可辨識故障診斷、未見組合的有效修復。它們不是完整理解或唯一因果模型的證明。
- **持續改善**：在固定未見測試上，歷史累積後有可比較收益，而非後面的任務剛好較簡單。

模型參數可以保持不變；若證據支持外部經驗帶來跨任務改進，應明確稱「系統層級的經驗轉移」，不暗示完成權重訓練。

## 2. 主要研究問題

| RQ | 問題 | 支持證據 | 可否證的情況 |
| --- | --- | --- | --- |
| RQ1 | 哪種經驗對新農場有幫助，哪種會誤導？ | 相同任務的無歷史、原始歷史與普通筆記比較；按適用／無關／前提不同分層 | 沒有穩定效果，或差異主要來自資料量／難度 |
| RQ2 | 適用性檢查是否有超過普通推理的價值？ | 同一結構化經驗，開關額外檢查；成功與完整成本共同分析 | 更強模型自行處理已同樣好，或檢查成本抵銷收益 |
| RQ3 | 選擇診斷實驗是否比反覆改設計有效？ | 固定候選池，只改選擇策略；另測完整生成流程 | 方法只產生比較好的候選，排序本身沒有作用；或多做測試反而浪費 |
| RQ4 | 收益是否跨設計，且不傷害仍有效的舊經驗？ | 留出組合／lineage／操作條件，修正後回歸；不同模型內重跑 | 只在近重複藍圖、单一模型或單一順序有效 |

第一個主比較聚焦 RQ1／RQ2；RQ3 的最小消融用來解釋方法收益，RQ4 按資源擴大。未量測的 RQ 不放進摘要成果。

## 3. 假說的正確寫法

可使用下列方向作預註冊起點，不填尚未測得的百分比：

H1：在經驗適用的任務上，歷史重用能降低達標成本；在前提不同而表象相似的任務上，普通重用可能變差。

H2：在相同經驗、模型與預算下，額外適用性檢查可改善前提不同任務的成本—成功率取捨；其收益不足以抵銷成本也屬可能結果。

H3：由可辨別預測和成本選擇的測試，可優於固定順序、最便宜優先或強模型自由選擇中的部分基線。不能預設一定全面優勝。

正式數值門檻、主要比較與分析方法在 pilot 後、正式測試開封前固定。不得看完結果才改成最容易勝出的敘述。

## 4. 可以形成什麼貢獻？

### 評測貢獻

新的任務與實驗協定若能區分「記住藍圖」「重用一般程序」「辨認適用條件」「診斷局部差異」，並有可重現強基線，可形成評測貢獻。只增加方塊數、列更多農場名稱或重新包裝現有 benchmark 不足。

### 方法貢獻

需要指出具體新增的決策：如何確認前提、選何種測試、何時停止驗證並直接修復。必須與最接近既有方法及簡單策略比較；卡片格式、資料庫、MCP、反思角色與新縮寫本身不是演算法贡献。

### 實證貢獻

若用受控變因釐清抽象程度、經驗數量、任務條件及模型能力如何影響正負遷移，可形成實證研究。結果即使不支持 CDET，也應完整報告；但常識性結論、小樣本波動或不公平負結果不自動有發表價值。

三種貢獻可以並存，不必硬湊。最終題目與摘要以實際完成的工作為準。

## 5. 如何區分相關性與原因？

固定遊戲規則、模型、工具、初始條件、可用歷史與預算，改變明確宣告的表示法或控制策略。對「某種經驗造成誤導」至少需要移除該類經驗、替換不相關經驗或可重跑的配對消融，而不是只讀 Agent 的文字理由。

原始歷史、摘要、結構化經驗的比較會同時影響可見上下文與搜尋成本。應保留共用原始資料入口，並額外用「同一結構化內容，不啟用額外 gate」區分格式與決策效果。

完整自主累積時，不同策略產生不同歷史，測到的是整體系統效果；不能把全部收益歸因於 memory schema。兩種實驗分開，見 [05](05-evaluation-protocol.md)。

## 6. 更強模型能否取代方法？

可能。強模型仍可能需要取得新觀察，但它未必需要我們的外部控制策略。較強模型直接搜尋原始證據就能同樣有效時，應降低方法必要性主張，或只保留環境與實證結論。

因此主要比較在同一模型內進行；若換模型，每組重新跑。先完成一個具代表性的強模型 pilot，再視資源加入第二個模型；不能拿舊模型無記憶對比新模型加方法。模型、API 日期、推理設定與可用快照都記錄。

## 7. 為何仍值得研究？

舊經驗有用與有害已不是新現象；選擇性重用、驗證、反證與實驗規劃也有文獻。候選切入點是：在多機制、持續產出的完整工程系統中，測試跨設計重用的適用性，以及對實際修復成本與功能的影響。

這是候選研究範圍，不是已確認無先例的空白。每次對外主張前依 [08](08-related-work.md) 比較已公開的方法與設定。不要因另一篇論文未測 Minecraft，就宣布它與本研究無關。
