# 未產品化的點子清單（2026-09-19）

每個點子三行：是什麼、好在哪、難在哪。編號是穩定 ID，後文引用用 ID。

## 1. 版本帳（I-01–I-08）

- I-01 分支語料：chunks 進可定址樹，按假設開分支，diff 和 blame 變檢索算子 [S-V11]。
  好在代理能安全試錯；難在向量庫和版本庫活在兩個世界。
- I-02 雙時鐘：世界真值和入庫時間分開查，舊韌體答舊答案 [S-V12]。
  好在根治過期教程；難在 RAG 只有一個時間欄。
- I-03 釘住源版本：派生物釘源 hash，源一動就掛過期徽章，不靜默錯 [S-C1]。
  好在幾天就有回報；難在所有緩存都要帶版本 pin。
- I-04 硬邊界清單：產品、版本範圍、加載器、依賴四元組，不相容永不共檢索 [S-C3]。
  好在根治跨線污染；難在元數據要是求解器不是標籤。
- I-05 版本刻面搜尋：預設精確匹配，跨版折疊提示可能不 work [S-C3]。
  好在 UX 誠實；和 I-04 配對做。
- I-06 墓碑預設：刪只標記不真刪，查詢過濾，後台回收，可回滾 [S-C5]。
  好在消滅孤兒向量；難在索引時就要存 ID 映射。
- I-07 差異索引：只重嵌改動塊，能回答兩版之間變了什麼 [S-C5]。
  好在帳本變差異引擎；難在要接 CDC 和雙索引切換。
- I-08 釘住解析器版本：prod 鎖版本，dev 才用最新，藍圖可重現 [S-M8]。
  好在可重現；難在要同時維護舊管線。

## 2. 軌跡和控制器（I-09–I-15）

  好在別名和壞模式自己浮現；難在要留 transcript 加審查隊列。
