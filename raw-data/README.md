# 原始研究素材

此目錄保留先前取得的術語、技術文章、機器目錄及社群資料。它們是可評估的研究線索，不是已完成的農場資料集、已驗證機制或新系統資料庫。

現行研究見 [計畫索引](../docs/README.md)，開始實驗見 [P0 工作表](../docs/experiments/p0-first-farm.md)。第一輪不要求先匯入本目錄的全部內容。

## 素材用途

| 位置 | 可評估用途 | 限制 |
| --- | --- | --- |
| `dictionary/` | 術語與別名參考 | 保留原授權；來源審核狀態不等於遊戲機制已被本研究驗證 |
| `gtmc-database/` | 按需閱讀的技術文章與圖片 | 逐篇確認版本、作者、來源及使用條件 |
| `machines/` | 人類設計目錄與藍圖線索 | 目錄列有檔名不代表已取得藍圖或確認能運行 |
| `legacy/` | 社群歷史資料與舊翻譯候選 | 不繼承其他目錄的授權，也不自動成為可信筆記 |
| `TechMC Glossary.csv` | 待審術語資料 | 來源與再散布權待確認，不因已存在此處就視為可公開使用 |

完整來源限制統一在 [資料與安全](../docs/plan/07-data-and-safety.md)。部分既有素材的歷史政策為 internal；repository 目前可見性與權利之間仍需擁有者審查，本次整理不代表完成授權或隱私查核。

本機可能另有 Git 忽略的 Minecraft source，新的 clone 不保證包含；不得把遊戲原始／反編譯程式提交或再散布。先前目錄與檔案數是歷史盤點，不是本輪重新測量。

## 使用原則

原始 bytes、來源檔與授權檔保持不變。需要清理、轉換或建立索引時，另產生衍生物並綁來源版本與 hash，不直接覆寫來源以符合新欄位。

可追溯不代表正確，可搜尋不代表已授權，AI 摘要也不會自動改變再散布限制。首輪實驗優先採自建／明確授權的農場與實驗紀錄，確定需要資料後再按相同權限提供給各基線。
